🎤 അന്താക്ഷരി ലൈവ് (Antakshari Live)

അന്താക്ഷരി ലൈവ് is an interactive, real-time multiplayer music party game web application designed for friends and families to play Antakshari online. Built with a responsive, modern UI, voice streaming, and dynamic game management features.

🌟 Key Features

Real-Time Multiplayer: Host private lobbies or join existing active game groups using a 4-character invite code.

Live Voice Interaction: Integrated peer-to-peer audio streaming via PeerJS, allowing players to sing live during their turns.

Dynamic Turn & Game Rules:

Automated round timers and voting system (👍 Valid / 👎 Invalid).

First-letter/last-letter song chaining rules.

"Raise Hand" fallback mechanic for skipped turns.

⚡ Rapid Fire Tie-Breakers: Buzz-in gameplay mode for handling tie scores.

User Authentication & Accounts: Google Sign-In via Firebase for saving match histories, player avatars, friend lists, and global leaderboard rankings.

Integrated Live Chat: In-game text messaging during gameplay.

Admin & Moderation Tools: Dedicated admin dashboard, user reporting system, and kicking/moderation capabilities for room hosts.

Malayalam Localization & Fonts: Custom typography featuring Malayalam fonts (Gayathri and Manrope).

🛠️ Tech Stack & Dependencies

Frontend: HTML5, CSS3, Modern Modular JavaScript (ES6 Modules)

Real-Time Voice Streaming: PeerJS (WebRTC)

Backend & Database: Google Firebase (Authentication, Cloud Firestore)

Typography: Google Fonts (Gayathri, Manrope)
